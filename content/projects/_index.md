## 🎭 Murder Mystery Games

### Artefactum: AI-Powered Mystery Generator

**Automated system for generating complete murder mystery games in 3 hours**

Production-ready pipeline that generates 12-player murder mystery dinner parties from scratch. Built with unconventional tools: Groq (0.3s inference), DSPy (structured LLM programs), Typst (2s PDF compilation), custom ontologies, and graph-based validation.

**What it generates:**
- 12 character dossiers (professional PDFs)
- 14 clues + 36 objectives + 44 physical props
- 132 validated character relationships
- Interactive web dashboard with 3D network graphs
- Complete GM materials + deployment package

**Status:** Production-ready, commercially viable
**Tools:** DSPy, Groq, Typst, Vis.js, Pydantic, Python
**Innovation:** Multi-stage generation pipeline with graph validation

## 💼 Event Planning

### EventFlow: AI-Powered Event Management Platform

**Full-stack event planning platform built in 2 weeks**

A production-ready SaaS platform for chaotic planners who have creative vision but scattered execution. Built to solve my own organizational chaos while planning elaborate events.

**What makes it different:**
- **Caroline AI:** 47 type-safe tools, 87.5% accuracy extracting structured data from messy meeting notes
- **Type-safe from LLM → Database:** Pydantic schemas + JSON mode = Caroline can't corrupt data even if she hallucinates
- **Review workflow:** Planner approves before database commit (AI suggests, human confirms)
- **Built for chaos:** Works with interrupted, conflicting, multi-language notes

**Features:**
- AI-powered meeting extraction
- Vendor marketplace + analytics
- Guest RSVP system + task templates
- Real-time collaboration
- Mobile-optimized interface

**Status:** Feature-complete, production-ready
**Tech Stack:** FastAPI, Bootstrap 5, SQLite/PostgreSQL, Pydantic
**Using it for:** An actual wedding (survival mode = best motivator)
